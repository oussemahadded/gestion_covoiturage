Projet : Application Web de Gestion de Covoiturage
1️⃣ Présentation Générale
1.1 Contexte

Le covoiturage est une solution moderne permettant de :

Réduire les coûts de transport

Diminuer la pollution

Faciliter les déplacements entre étudiants ou employés

Ce projet consiste à développer une application web permettant de gérer les offres et demandes de covoiturage.

1.2 Objectif du projet

Développer une application web permettant :

Aux conducteurs de publier des trajets

Aux passagers de rechercher et réserver des trajets

À l’administrateur de gérer la plateforme

2️⃣ Périmètre du projet

L’application contiendra :

Une interface utilisateur

Une base de données

Un système d’authentification

Un espace administrateur
